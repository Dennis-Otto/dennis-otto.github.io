# Dennis Otto

Open-source projects for the smart home, the document archive and the work on GitHub. Each one comes with tests, signed releases, security checks and bots that look after it, and each has a website of its own.

<div class="grid cards" markdown>

- :material-bullseye-arrow:{ .lg .middle } **Autodarts for Home Assistant**

    ---

    Local realtime control of an Autodarts board in Home Assistant: X01, Cricket, party and training games, tournaments and a bot, statistics with heatmaps, dashboard cards and blueprints, games started by voice. No cloud account needed.

    [:material-download: Install with HACS](https://my.home-assistant.io/redirect/hacs_repository/?owner=Dennis-Otto&repository=ha-autodarts&category=integration){ .md-button .md-button--primary }
    [:material-book-open-variant: Documentation](https://dennis-otto.github.io/ha-autodarts/){ .md-button }

- :material-file-sync:{ .lg .middle } **Paperless Sync**

    ---

    A Nextcloud app that mirrors the finished documents of Paperless-ngx into a structured archive in Nextcloud, for Files, the desktop and mobile clients, sharing and the viewer. It can also hand files from a Nextcloud inbox to Paperless.

    [:material-download: Nextcloud App Store](https://apps.nextcloud.com/apps/paperless_sync){ .md-button .md-button--primary }
    [:material-book-open-variant: Documentation](https://dennis-otto.github.io/paperless-sync/){ .md-button }

- :material-file-search:{ .lg .middle } **Paperless Unified Search**

    ---

    The OCR and full-text search of Paperless-ngx in the search of Nextcloud. A result opens the synchronized file right in the viewer of Nextcloud.

    [:material-download: Nextcloud App Store](https://apps.nextcloud.com/apps/paperless_unified_search){ .md-button .md-button--primary }
    [:material-book-open-variant: Documentation](https://dennis-otto.github.io/paperless-unified-search/){ .md-button }

- :material-robot-happy:{ .lg .middle } **Issue assistant**

    ---

    A GitHub Action that looks after the issues of a repository: a first analysis by an AI that only reads, labels, duplicates, reminders for open questions, and the way from the fix to the release.

    [:material-github: Use the action](https://github.com/Dennis-Otto/issue-assistant#set-up-a-repository){ .md-button .md-button--primary }
    [:material-book-open-variant: Documentation](https://dennis-otto.github.io/issue-assistant/){ .md-button }

- :material-file-tree:{ .lg .middle } **Repo Blueprint**

    ---

    The Copier template all of these projects are made from: tests on every change, a release bot, security checks and the settings of the repository as code, for seven kinds of projects. A bot brings every repository up to each new release.

    [:material-rocket-launch: Start a repository](https://github.com/Dennis-Otto/repo-blueprint#start-a-repository){ .md-button .md-button--primary }
    [:material-book-open-variant: Documentation](https://dennis-otto.github.io/repo-blueprint/){ .md-button }

- :material-view-dashboard:{ .lg .middle } **Repository dashboard**

    ---

    The state of every repository at a glance: checks, releases, open pull requests, security findings and the version of the blueprint.

    [:material-arrow-right: Open the dashboard](https://dennis-otto.github.io/repo-blueprint/dashboard/){ .md-button .md-button--primary }

</div>

Questions and ideas belong in the repository of each project; vulnerabilities are reported privately, as its security policy describes. If the projects are useful to you, you can [support their development](https://github.com/sponsors/Dennis-Otto).
