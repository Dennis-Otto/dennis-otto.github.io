# Dennis Otto

Open-Source-Projekte für das smarte Zuhause, das Dokumentenarchiv und die Arbeit auf GitHub. Jedes bringt Tests, signierte Releases, Sicherheitsprüfungen und Bots mit, die sich darum kümmern, und jedes hat eine eigene Website.

<div class="grid cards" markdown>

- :material-bullseye-arrow:{ .lg .middle } **Autodarts für Home Assistant**

    ---

    Ein Autodarts-Board lokal und in Echtzeit aus Home Assistant steuern: X01, Cricket, Party- und Trainingsspiele, Turniere und ein Bot, Statistiken mit Heatmaps, Dashboard-Karten und Blueprints, Spiele per Sprache starten. Ganz ohne Cloud-Konto.

    [:material-download: Mit HACS installieren](https://my.home-assistant.io/redirect/hacs_repository/?owner=Dennis-Otto&repository=ha-autodarts&category=integration){ .md-button .md-button--primary }
    [:material-book-open-variant: Dokumentation](https://dennis-otto.github.io/ha-autodarts/de/){ .md-button }

- :material-file-sync:{ .lg .middle } **Paperless Sync**

    ---

    Eine Nextcloud-App, die die fertigen Dokumente aus Paperless-ngx in ein geordnetes Archiv in Nextcloud spiegelt, für Dateien, die Desktop- und Mobil-Clients, das Teilen und den Viewer. Auf Wunsch reicht sie Dateien aus einem Nextcloud-Eingang an Paperless weiter.

    [:material-download: Nextcloud App Store](https://apps.nextcloud.com/apps/paperless_sync){ .md-button .md-button--primary }
    [:material-book-open-variant: Dokumentation](https://dennis-otto.github.io/paperless-sync/){ .md-button }

- :material-file-search:{ .lg .middle } **Paperless Unified Search**

    ---

    Die OCR- und Volltextsuche von Paperless-ngx in der Suche von Nextcloud. Ein Treffer öffnet die synchronisierte Datei direkt im Viewer von Nextcloud.

    [:material-download: Nextcloud App Store](https://apps.nextcloud.com/apps/paperless_unified_search){ .md-button .md-button--primary }
    [:material-book-open-variant: Dokumentation](https://dennis-otto.github.io/paperless-unified-search/){ .md-button }

- :material-robot-happy:{ .lg .middle } **Issue assistant**

    ---

    Eine GitHub Action, die sich um die Issues eines Repositorys kümmert: eine erste Analyse durch eine KI, die nur liest, Labels, Duplikate, Erinnerungen an offene Fragen und der Weg vom Fix bis zum Release.

    [:material-github: Action einsetzen](https://github.com/Dennis-Otto/issue-assistant#set-up-a-repository){ .md-button .md-button--primary }
    [:material-book-open-variant: Dokumentation](https://dennis-otto.github.io/issue-assistant/){ .md-button }

- :material-file-tree:{ .lg .middle } **Repo Blueprint**

    ---

    Die Copier-Vorlage, aus der all diese Projekte entstehen: Tests bei jeder Änderung, ein Release-Bot, Sicherheitsprüfungen und die Einstellungen des Repositorys als Code, für sieben Arten von Projekten. Ein Bot bringt jedes Repository auf jede neue Version.

    [:material-rocket-launch: Repository anlegen](https://github.com/Dennis-Otto/repo-blueprint/blob/main/README.de.md){ .md-button .md-button--primary }
    [:material-book-open-variant: Dokumentation](https://dennis-otto.github.io/repo-blueprint/de/){ .md-button }

- :material-view-dashboard:{ .lg .middle } **Repository-Dashboard**

    ---

    Der Zustand aller Repositorys auf einen Blick: Prüfungen, Releases, offene Pull Requests, Sicherheitsfunde und die Version des Blueprints.

    [:material-arrow-right: Dashboard öffnen](https://dennis-otto.github.io/repo-blueprint/dashboard/){ .md-button .md-button--primary }

</div>

## Unterstützung

Fragen und Ideen gehören ins Repository des jeweiligen Projekts; Sicherheitslücken werden vertraulich gemeldet, wie es dessen Sicherheitsrichtlinie beschreibt. Wenn dir die Projekte nützen, kannst du [ihre Entwicklung unterstützen](https://github.com/sponsors/Dennis-Otto).
