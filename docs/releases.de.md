# Neuigkeiten

<!-- This page is the German translation of docs/releases.md: change both together. The hooks put the releases of every project in place of the marker below while MkDocs builds the website, with their notes from GitHub, which stay in English. -->

Was sich in jedem Projekt geändert hat, Release für Release: die Notizen der letzten fünf Releases jedes Projekts, die neuesten zuerst, in den Worten ihrer Nutzer, so wie jedes Projekt sie in sein Changelog schreibt. Die Notizen sind auf Englisch, wie die Changelogs. Ein Release, das nach dem Bau dieser Seite erschienen ist, steht unter der Überschrift seines Projekts, mit einem Link zu seinen Notizen auf GitHub. Der [Feed aller Releases](https://dennis-otto.github.io/repo-blueprint/dashboard/releases.atom) bringt jedes neue in einen Feedreader, und das [Dashboard](https://dennis-otto.github.io/repo-blueprint/dashboard/) zeigt den Stand jedes Projekts.
